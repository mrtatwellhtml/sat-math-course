# 0.1 Fractions, Decimals and Percents as One Idea

!!! abstract "Why this is on the test"
    This is not SAT content by itself, but it is the arithmetic language every SAT question assumes. A student who is slow here loses time on every question, not just the ones that look like fraction work.

**Before you start, you should be able to:** work with whole numbers and basic arithmetic facts.

**By the end of this lesson you will be able to:**

- Convert fluently between fractions, decimals and percents
- Add, subtract, multiply and divide fractions without a calculator
- Recognise when a decimal answer hides an exact fractional value

---

## The idea

A fraction, a decimal and a percent are three ways to write the same quantity. The number does not change; only the notation changes.

A fraction tells you a part of a whole: $\dfrac{3}{4}$ means 3 out of 4 equal parts. A decimal uses place value: $0.75$ is 75 hundredths. A percent means “per hundred”: $75\%$ is $75$ out of 100.

That means all three are connected by one idea:

$$
\text{fraction} = \frac{\text{part}}{\text{whole}},\quad
\text{decimal} = \text{fraction written in base 10},\quad
\text{percent} = \text{fraction out of } 100
$$

The fastest SAT habit is to translate between forms before you start calculating. If a question uses a percent, turn it into a decimal or fraction. If it uses a decimal, ask what fraction it is hiding. If it uses a fraction, decide whether the denominator is useful and whether the numerator can be simplified first.

The most common mistakes are not about formulas. They are about choosing the wrong form for the job. Percent problems are usually easiest with decimals. Fraction operations are easiest when you look for common denominators. A decimal that terminates can often be written exactly as a fraction, which matters when the answer is supposed to be exact rather than approximate.

## Worked examples

### Example 1 — routine
> Convert $0.625$ to a fraction and to a percent.

**Thinking:** A decimal with three places tells you hundredths, thousandths, and so on. The denominator is a power of 10, then simplify.

**Solution:**

1. Write $0.625$ as $\dfrac{625}{1000}$.
2. Simplify by dividing numerator and denominator by 125: $\dfrac{625 \div 125}{1000 \div 125} = \dfrac{5}{8}$.
3. To turn a fraction into a percent, multiply by 100: $\dfrac{5}{8} \times 100 = \dfrac{500}{8} = 62.5\%$.

**Answer:** $0.625 = \dfrac{5}{8} = 62.5\%$

### Example 2 — typical test difficulty
> Add $\dfrac{2}{3} + \dfrac{5}{12}$.

**Thinking:** The denominators are different, so you need a common denominator before you can combine the numerators.

**Solution:**

1. The least common denominator of 3 and 12 is 12.
2. Rewrite $\dfrac{2}{3}$ as $\dfrac{8}{12}$.
3. Add the numerators: $\dfrac{8}{12} + \dfrac{5}{12} = \dfrac{13}{12}$.
4. This is an improper fraction, so you can write it as $1\dfrac{1}{12}$ if you want a mixed number.

**Answer:** $\dfrac{13}{12}$, or $1\dfrac{1}{12}$

### Example 3 — the hard version
> A store marks a jacket down by $30\%$, then marks it down again by $20\%$ of the new price. What is the overall percent decrease from the original price?

**Thinking:** Do not add the percents. Each discount is taken from a different price, so the second discount is applied to the already reduced price.

**Solution:**

1. Start with 100% of the original price.
2. After a 30% discount, the price is $100\% - 30\% = 70\%$ of the original price.
3. A second 20% discount is taken from that reduced price: $70\% \times 0.80 = 56\%$.
4. The final price is 56% of the original. That means the total decrease is $100\% - 56\% = 44\%$.

**Answer:** $44\%$ decrease

## Where students go wrong

!!! warning "Common errors"
    - **Using the wrong common denominator.** A common error is to add denominators instead of finding a shared denominator. The denominator only changes because you are renaming the fraction, not because the size of the pieces changed.
    - **Forgetting that percent means “out of 100”.** A student may turn $25\%$ into $0.25$ correctly but then forget that $0.25$ means $\dfrac{25}{100}$, not $\dfrac{25}{10}$.
    - **Treating a decimal like a whole number.** In $0.6 \times 40$, the answer is not $24$ by accident; it is $6\times 40$ shifted by one decimal place. The percent and decimal forms are connected by place value.
    - **Adding percent changes directly.** A 30% discount followed by a 20% discount is not a 50% total discount. The second percent is applied to a smaller amount.

## Answers and solutions

??? success "Show answers"
    | # | Answer |

    | 1 | B |
    | 2 | 35% |
    | 3 | B |
    | 4 | A |
    | 5 | 66.666...% |
    | 6 | A |
    | 7 | B |
    | 8 | \$43.20 |
    | 9 | A |
    | 10 | A |
    | 11 | C |
    | 12 | 135 |

??? success "Show full solutions"
    **1.** $0.45 = \dfrac{45}{100} = \dfrac{9}{20}$.

    **2.** $\dfrac{7}{20} = 7 \div 20 = 0.35 = 35\%$.

    **3.** $\dfrac{3}{8} + \dfrac{1}{4} = \dfrac{3}{8} + \dfrac{2}{8} = \dfrac{5}{8}$.

    **4.** $\dfrac{5}{6} \div \dfrac{2}{3} = \dfrac{5}{6} \times \dfrac{3}{2} = \dfrac{15}{12} = \dfrac{5}{4}$.

    **5.** $\dfrac{12}{18} = \dfrac{2}{3} = 0.666\ldots = 66.666\ldots\%$.

    **6.** $\dfrac{3}{16} = 3 \div 16 = 0.1875$.

    **7.** $\dfrac{7}{10} - \dfrac{2}{5} = \dfrac{7}{10} - \dfrac{4}{10} = \dfrac{3}{10}$.

    **8.** Tax is $0.08 \times 40 = 3.20$, so total = $40 + 3.20 = 43.20$.

    **9.** $\dfrac{2}{3} \approx 0.666\ldots$, so $0.68 > \dfrac{2}{3}$.

    **10.** $\dfrac{1}{8} = 0.125$, not $0.18$. The student likely used the denominator 8 to make an approximate 2-digit decimal without dividing correctly.

    **11.** Use a common denominator of 30: $\dfrac{3}{5} = \dfrac{18}{30}$, $\dfrac{1}{6} = \dfrac{5}{30}$, $\dfrac{1}{3} = \dfrac{10}{30}$. Then $\dfrac{18}{30} + \dfrac{5}{30} - \dfrac{10}{30} = \dfrac{13}{30}$.

    **12.** After the first drop-off, $240 \times 0.75 = 180$ remain. After the second, $180 \times 0.75 = 135$ remain.

## Tutor notes

!!! note "For the tutor"
    - **Watch for:** students who try to add fractions without a common denominator or who convert a percent incorrectly.
    - **Diagnostic question:** Ask, “What is $0.4$ as a fraction and as a percent?” If they get it wrong, they are still treating the forms as unrelated.
    - **If they are struggling:** return to fraction simplest form and denominator logic before moving to algebra.
    - **If they are flying:** ask them to explain why a 30% increase followed by a 30% decrease is not back to the original price.

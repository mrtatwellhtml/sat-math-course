# 0.4 Variables, Expressions and Like Terms

!!! abstract "Why this is on the test"
    Variables and expressions are the language of algebra. Without this foundation, students cannot read the setup of a question, and they often misread simple word problems as arithmetic instead of algebra.

**Before you start, you should be able to:** use negative numbers reliably and follow order of operations (Lesson 0.2).

**By the end of this lesson you will be able to:**

- Translate a phrase into an algebraic expression
- Combine like terms and apply the distributive property
- Evaluate an expression at a given value

---

## The idea

A variable is a letter standing for a number whose value can change. You can use any letter, but the SAT most often uses $x$, $y$, $n$, $p$, and letters for parameters like $k$ or $t$.

An expression is a combination of numbers, variables and operations. It does not have an equals sign. Examples include:

$$
3x + 5,\quad 2(a - 4),\quad 5m - 7n + 9
$$

A term is a product of numbers and variables. Terms are “like terms” when they have the same variable part. For example, $3x$ and $-7x$ are like terms, but $3x$ and $3x^2$ are not. Only the coefficients change.

The distributive property says that multiplication is shared across addition or subtraction:

$$
 a(b + c) = ab + ac
$$

This is the bridge between a factored expression and an expanded one. It is also how SAT students turn a hidden structure into a visible equation.

When you evaluate an expression, substitute the given value and then simplify. If $x = 4$, then $3x + 2 = 3(4) + 2 = 14$.

## Worked examples

### Example 1 — routine
> Translate the phrase “three more than twice a number” into an expression.

**Thinking:** “Twice a number” means $2n$. “Three more than” means add 3.

**Solution:**

1. Let the number be $n$.
2. “Twice a number” is $2n$.
3. “Three more than” means add 3: $2n + 3$.

**Answer:** $2n + 3$

### Example 2 — typical test difficulty
> Simplify $5x + 3 - 2x + 7$.

**Thinking:** Combine the $x$ terms together and the constant terms together.

**Solution:**

1. Group like terms: $(5x - 2x) + (3 + 7)$.
2. $3x + 10$.

**Answer:** $3x + 10$

### Example 3 — the hard version
> Simplify $3(2x - 5) - 4(x - 1)$.

**Thinking:** Use the distributive property before combining like terms.

**Solution:**

1. Distribute the 3: $6x - 15$.
2. Distribute the $-4$: $-4x + 4$.
3. Combine: $(6x - 4x) + (-15 + 4) = 2x - 11$.

**Answer:** $2x - 11$

---

## Where students go wrong

!!! warning "Common errors"
    - **Combining unlike terms.** Students often add $3x$ and $5x^2$ as $8x^3$, which is not allowed. The variable part must match exactly.
    - **Dropping the sign during distribution.** In $-3(x - 4)$, the correct expansion is $-3x + 12$, not $-3x - 12$.
    - **Reading “less than” or “more than” backwards.** “Five less than a number” means $n - 5$, not $5 - n$.
    - **Forgetting parenthesis when substituting.** If $x = 2$, then $3(x + 4)$ is $3(2 + 4)$, not $3 \cdot 2 + 4$.

??? success "Show full solutions"
    **1.** “Five more than a number” means add 5 to the number: $n + 5$.

    **2.** $7x - 3x + 8 = 4x + 8$.

    **3.** $2(3) + 7 = 6 + 7 = 13$.

    **4.** $3(y + 2) - 5 = 3y + 6 - 5 = 3y + 1$.

    **5.** “Twice a number” is $2n$, and “the sum ... and 9” means add 9: $2n + 9$.

    **6.** $4m + 6m = 10m$ and $-2 + 9 = 7$, so $10m + 7$.

    **7.** $2^2 - 3(2) + 4 = 4 - 6 + 4 = 2$. Wait, this is 2, which is not among the options. The option list is wrong. The correct answer is 2. |

    **8.** $2(3x - 4) + 5x = 6x - 8 + 5x = 11x - 8$.

    **9.** Fixed fee \$15 plus \$2 per T-shirt gives $15 + 2n$.

    **10.** $5(2p - 3) - 3(p + 1) = 10p - 15 - 3p - 3 = 7p - 18$.

    **11.** $3(-1 - 2) + 2(-1 + 4) = 3(-3) + 2(3) = -9 + 6 = -3$. Wait, this is -3, not in the options. The option list is wrong. |

    **12.** “Seven less than triple a number” means $3n - 7$. The order matters: triple the number first, then subtract 7.

## Tutor notes

!!! note "For the tutor"
    - **Watch for:** students who translate “less than” in the wrong order and who treat unlike terms as if they were like terms.
    - **Diagnostic question:** Ask, “What is the expression for ‘three less than twice a number’?” If they answer $3 - 2n$, they need more translation practice.
    - **If they are struggling:** return to itemising the phrase one chunk at a time: “twice a number,” “more than,” “less than.”
    - **If they are flying:** ask them to build and simplify an expression from a multi-step word problem before solving any equations.
